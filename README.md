The existing `repo.json` and `protected/repo.json` catalogs list the same package. There is no public plaintext V3.1 package or alternate public V3.1 URL.

This public repository has only the catalog, documentation and branding assets, with no old patch history. Catalog URLs remain unchanged.

Channel credentials embedded in the IPA can be extracted; this gate is not App Store attestation or a guarantee against modified clients or redistribution after an authorized download. Previously downloaded or cached copies cannot be recalled.

The replaced V3 file has been removed from the current branch. Do not commit client signing keys, administrator credentials, license keys, session tokens or plaintext V3.1 bytes to this public repository.
