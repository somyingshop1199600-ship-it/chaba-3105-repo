## Contents

CHABA contains the owner-supplied ROV CHABA update with camera-setting values 2.70 / 1.60 / 2.21. Both catalogs list it as CHABA and download `protected/packages/CHABA.3105` (relative to the repository root), encrypted for Build 16 and its licensed key service. Map HOK is retained separately. The original catalog OS range is retained; this is not a claim of game-device validation on every OS.

The current NoSlider update removes the Execute percentage control, restores the original code value, and adds a key-timer Execute driver. The owner confirmed that the functions work on their device. Existing KeyRecovery verification, denial/expiry and retry rules remain. The legacy encrypted asset path is retained as an alias to the same current encrypted bytes for existing clients.

Do not include login cookies, session tokens, passwords, signing credentials or GitHub access tokens.

Creating this repository does not change an installed CHABA app. Build 13 retains its existing repository until a separate app configuration change is made.
