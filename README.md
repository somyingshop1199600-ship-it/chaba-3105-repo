# CHABA Repository

The active package is **CHABASHOP V3.2**, using the owner's new original HeroSkin pair for RoV 1.64.1 with the R7 menu and functions. Published runtime resources match the supplied new-base test package; publication changes only its displayed project name.

- Manifest: https://raw.githubusercontent.com/somyingshop1199600-ship-it/chaba-3105-repo/main/repo.json
- Source catalog: https://raw.githubusercontent.com/somyingshop1199600-ship-it/chaba-3105-repo/main/sources.json

The existing `repo.json` and `protected/repo.json` catalogs list the same package. Downloads require **Build 1508 V31Protected**, a channel proof and a currently valid device-bound CHABA license. The original unprotected Build 1508 and earlier unmodified clients cannot download this release. Package bytes are stored privately in the existing CHABA delivery service, rather than committed here. The pinned download URL retains its V3_1 filename alias so the selected IPA can install V3.2 without an IPA update. The catalog and internal project both display V3.2.

Legacy package, decryption-key and retired web-upload download routes are closed. The previous repository's complete history and Releases are retained in a separate private repository. This public repository has only the catalog, documentation and branding assets, with no old patch history. Catalog URLs remain unchanged.

Channel credentials embedded in the IPA can be extracted; this gate is not App Store attestation or a guarantee against modified clients or redistribution after an authorized download. Previously downloaded or cached copies cannot be recalled.

The replaced V3 file has been removed from the current branch. Do not commit client signing keys, administrator credentials, license keys, session tokens or plaintext V3.1 bytes to this public repository.
