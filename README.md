# CHABA Repository

The active package is **CHABASHOP V3.4**, using the owner's R38 package for RoV 1.64.1. It includes the Billow S2 ten-second combat window, updated hero artwork and red login warning, with the retained BIJAN and THORNE functions. Published runtime resources match the supplied R38 package exactly; publication changes only its displayed project name.

- Manifest: https://raw.githubusercontent.com/somyingshop1199600-ship-it/chaba-3105-repo/main/repo.json
- Source catalog: https://raw.githubusercontent.com/somyingshop1199600-ship-it/chaba-3105-repo/main/sources.json

The existing `repo.json` and `protected/repo.json` catalogs list the same package. Downloads require **Build 1508 V31Protected**, a channel proof and a currently valid device-bound CHABA license. The original unprotected Build 1508 and earlier unmodified clients cannot download this release. Package bytes are stored privately in the existing CHABA delivery service. The pinned download URL retains its V3_1 filename alias so the selected IPA can install V3.4 without an IPA update. The catalog and internal project both display V3.4.

Legacy package, decryption-key and retired web-upload download routes are closed. The previous repository's complete history and Releases are retained in a separate private repository. This public repository has only the catalog, documentation and branding assets, with no old patch history. Catalog URLs remain unchanged.

Channel credentials embedded in the IPA can be extracted; this gate is not App Store attestation or a guarantee against modified clients or redistribution after an authorized download. Previously downloaded or cached copies cannot be recalled.

The catalogs contain one active package, replacing V3.3. Do not commit client signing keys, administrator credentials, license keys, session tokens or plaintext patch bytes to this public repository.
